Virtual Replica - Realistic Automotive Simulator

Realistic automotive simulator with cockpit and interactive GUI

Project Overview

Virtual Replica is an automotive simulator designed to visualize and test upstream prototypes and user experiences for EPICNPOC projects. This simulator, designed as a key feature, enables immersive visualization of technological innovations, effectively preparing concepts for trade show presentations.

The realistic and modular automotive simulator was part of the third step in the company's prototyping chain, according to the description on the EPICNPOC Prototyping Services website. My work involved developing a platform for presenting different concepts and prototypes, displaying them in the virtual car cockpit to test them in real-world situations.

Project Objectives

Virtual Cockpit Replica

Create a virtual replica of the car cockpit on which the company's interface projects are presented.

Realistic Environment

Develop an environment based on real roads, using authentic GPS data.

Dual Control System

Integrate automatic and manual control, controllable either by Logitech steering wheel and pedals, or by the company server.

GUI Integration

Display GUI (Graphical User Interface) and UX (User Experience) developed by the company in the simulator.

Server Communication

Ensure smooth and fast communication between the simulator and server for data exchange.

Development Methodology

EPICNPOC Context

To develop the automotive simulator, I had to optimize the use of available resources, given human and time constraints. I therefore conducted thorough research to identify and test existing Unity assets, less costly in terms of development time than creating all features from scratch.

Resource Optimization Approach

The development approach focused on leveraging existing Unity assets and frameworks while customizing them for specific EPICNPOC requirements. This strategy allowed for rapid prototyping while maintaining high-quality standards expected for trade show demonstrations.

Technical Challenges

  • Hardware Integration: Seamless integration of Logitech steering wheel and pedals with Unity physics system
  • Real-time GPS Processing: Converting real-world GPS coordinates into accurate virtual road networks
  • Server Communication: Implementing low-latency networking for remote control capabilities
  • GUI Overlay System: Creating flexible interface display system for various prototype demonstrations
  • Performance Optimization: Maintaining consistent frame rates while handling complex 3D environments and real-time data
